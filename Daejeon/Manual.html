장비 구성

스튜디오에는 카메라, 실시간모니터, 메인모니터, 컴퓨터, 프린터, 리모컨이 준비되어 있습니다.

1
라이트룸 실행

바탕화면에서 라이트룸(LrC)을 실행시켜 주세요.

⚠️ 컴퓨터가 꺼져 있다면 컴퓨터를 먼저 켠 후 라이트룸을 실행하세요.
2
연결전송된 촬영 시작

상단 파일 탭 → 연결전송된 촬영 → 연결전송된 촬영 시작 클릭!

3
세션 이름 입력

연결전송된 촬영 설정 창의 세션 이름에 성함을 입력한 후 확인 클릭!

4
촬영 컨트롤러 확인

화면 중간에 촬영 컨트롤러가 뜨면 준비완료! 아래 설정값을 확인해주세요.

📷 카메라명: Canon EOS R6
⏱️ 셔터: 100  |  조리개: 7.1  |  ISO: 200
🌞 WB: 자동
⚠️ 카메라없음으로 표시된다면, 카메라에 연결된 선들이 모두 잘 꼽혀있는지 확인한 후, 라이트룸을 재시작해주세요.

모든 모니터 화면이 잘 켜져 있는지 확인해주세요.

5
필터 적용

촬영 컨트롤러의 현상설정에서 사용자 사전 설정을 눌러 원하는 필터로 변경하세요.

우측 동그라미 버튼을 클릭하여 필터가 잘 적용되었는지 확인해주세요.

⚠️ 필터를 설정하신 뒤에 촬영 하셔야 필터가 적용됩니다!
6
리모컨 선택 및 촬영 시작

사용하는 리모컨의 종류를 선택하세요.

무선리모컨 사용 시 → 리모컨 선택기 ① 버튼
유선리모컨 사용 시 → 리모컨 선택기 ② 버튼
💡 리모컨 사용 후 반드시 제자리에 넣어주세요!!

리모컨을 눌렀을 때 모니터에 촬영 결과가 나오면 준비 끝! 즐거운 촬영 시작!!

1
현상탭으로 이동

우측 상단의 현상 또는 D를 눌러 현상탭으로 이동하세요. F7을 눌러 왼쪽 패널(사전설정 목록)을 열어주세요.

2
필터 변경할 사진 선택

화면 하단에 뜬 촬영사진 중 필터 변경을 원하는 사진을 선택한 뒤, Ctrl을 클릭하여 나머지 사진도 선택해주세요.

3
변경할 필터 선택

사전설정 목록에서 원하시는 필터를 클릭하여 변경해주세요.

4
설정 동기화

상단 설정 탭 → 설정 동기화 클릭!

동기화 창이 뜨면 동기화 버튼 클릭!

💡 동기화 작업은 1장당 1초 정도 소요됩니다. 완료될 때까지 기다려주세요~
1
전체 선택 후 내보내기

화면 하단 촬영사진 중 하나를 선택한 뒤 Ctrl+A로 전체 선택 → 우클릭 → 내보내기 → 내보내기 클릭!

⚠️ 사진 전체를 선택해야 합니다!
2
성함 입력 후 내보내기

하위 폴더에 넣기에 고객님 성함을 입력한 후 내보내기 클릭!

⚠️ 저장경로 및 다른 설정은 절대 건드리시면 안됩니다!
3
사진저장

화면 좌측 상단에 내보내기 현황이 표시됩니다. 100장 기준 약 3분 소요됩니다.

바탕화면에 성함으로 된 폴더가 생성됩니다.

1
인쇄탭 이동 및 템플릿 선택

우측 상단의 인쇄 또는 Ctrl + Alt + 6를 눌러 인쇄탭으로 이동하세요.
F7을 눌러 왼쪽 패널(템플릿 브라우저)을 열어주세요. 비프레임스튜디오_사진인화 템플릿을 선택해주세요.

2
사진 선택

화면 하단에 뜬 사진 중 인화할 사진을 골라, 준비된 포스트잇에 선택한 사진이름을 적어주세요.

3
인화지 & 종이액자 꺼내기

필요한 수량의 인화지와 종이액자를 꺼내주세요.

💡 인화지 수량 안내
인원인화지 수량
1인당2장
4
인화지 프린터에 넣기

인화면이 앞을 보게 인화지를 넣어주세요.

5
사진 인쇄하기

F8을 눌러 오른쪽 패널(인쇄작업)을 열고, 인쇄 버튼을 클릭해주세요.

⚠️ 다른 설정은 절대 건드리지 마시고 인쇄 클릭!
1
사진 폴더 압축하기

내보내기가 완료된 사진 폴더를 우클릭 메뉴에서 압축하기 클릭!

2
원본 전송하기

생성된 압축파일을 이메일, USB 등 원하는 매체로 전송!

카카오톡으로 전송 시 최대 100장씩 선택하여 채팅창으로 끌어오기 → 묶어보내기로 진행!

💡 카카오톡 이용 시, 최대 100장씩 선택하여 묶어보내기로 진행해주세요.
3
바탕화면 폴더 & 압축파일 삭제

원본 전송 후 바탕화면에 폴더와 압축파일을 삭제해주세요.

4
라이트룸 사진 제거

라이트룸에서 전체 선택 (Ctrl+A) 후 우클릭 → 사진 제거 클릭!

⚠️ 다음 고객님을 위해 반드시 사진 제거를 완료해 주세요!
